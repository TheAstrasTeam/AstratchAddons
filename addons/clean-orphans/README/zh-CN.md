# 清理孤立积木

在工作区右键菜单中添加"清理孤立积木"按钮，用于删除未连接到任何根积木（如事件帽子块）的孤立积木。

## 设置项

| 名称 | 默认值 | 说明 |
| --- | --- | --- |
| 打开菜单时扫描孤立积木 | `true` | 打开右键菜单时预先扫描孤立积木 |

### 打开菜单时扫描孤立积木

**启用时**（默认），每次右键点击工作区都会执行一次 BFS 遍历来检测孤立积木，菜单标签会显示当前孤立积木数量（例如"清理孤立积木 (3)"），方便在删除前了解情况。

**禁用时**，打开右键菜单时不会进行 BFS 扫描，菜单始终显示通用的"清理孤立积木"标签且不带数量，只有在你实际点击按钮时才会执行扫描。对于积木数量较多的大型项目，这可以显著提升性能，因为遍历不再在每次右键点击时触发。
