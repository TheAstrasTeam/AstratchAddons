# 清理孤立积木

在工作区右键菜单添加「清理孤立积木」按钮。

## 什么是孤立积木？

孤立积木是指**未与任何根积木（脚本起点）相连的积木**。根积木是没有 `previousConnection` 且没有 `outputConnection` 的积木——通常是启动脚本的事件帽子块。

例如，如果你从「当绿旗被点击」脚本中断开一个积木，被断开的积木就会成为孤立积木。

## 使用方法

1. 启用此插件
2. 在工作区空白处右键（不要右键点击积木）
3. 点击 **「清理孤立积木」**
4. 所有孤立积木将被一次性删除

如果没有孤立积木，该菜单项会显示为灰色不可点击。

## 注意事项

- 所有被删除的孤立积木会被归入同一次撤销操作——按 Ctrl+Z 即可一次性恢复。
- 只影响主工作区上的积木，工具箱中的积木不受影响。
